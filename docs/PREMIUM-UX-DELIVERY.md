## Assessment (Simple Browser)

|------|--------|---------------|
| Navbar | Plain chip row | Utility bar + premium pills + Hot Deals flame + Categories megamenu |
| Under hero | Flat empty sections | Trust band, photo-tile categories, deal rails, toned promo cards, FAQ, testimonials |

| Empty catalog | Broken empty grids | Featured + Deal of Day hide until products exist; merch-ready banner explains |

## Homepage flow (live)

1. Rotating announcement (delivery / COD / returns)  
2. Utility bar + premium header  
3. Full-bleed styled hero (upload campaign art when ready)  
4. Trust strip  
5. Shop-by-category tiles  
6. Merch-ready (only while catalog empty)  
7. Deal rails (4 campaign cards)  
8. Trending / Deal of Day / Best Sellers (appear when collections filled)  
9. Promo banners → Testimonials → Home FAQ → Coupon → Newsletter  

## Merchant checklist (required for full premium)

1. Publish products; create `hot-deals` + `best-sellers` collections  
2. Bind those collections in Theme Editor on Featured / Deal of Day  
3. Upload hero + category + deal-rail images  
4. Set logo, WhatsApp, support phone; rename store from “My Store 6”  
5. Create FAQ + Track Order pages; wire header handles
